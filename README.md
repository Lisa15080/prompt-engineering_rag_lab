# Поиск информации в документах с помощью RAG и GigaChat

Учебный проект по дисциплине «Промпт-инженерия». Цель — реализовать поиск информации по документам с использованием технологии Retrieval-Augmented Generation (RAG) и языковой модели GigaChat.

## О проекте

В работе рассматривается применение RAG для ответов на вопросы по содержимому научных статей. Вместо того чтобы полагаться только на знания языковой модели, система сначала находит подходящие фрагменты в подготовленной коллекции документов, а затем использует их как контекст для формирования ответа.

Проект позволяет на практике познакомиться с векторным поиском, эмбеддингами и интеграцией LLM в Python-приложение.

## Используемые технологии

- Python
- LangChain — работа с документами и компонентами RAG
- GigaChat — языковая модель для формирования ответов
- GigaChatEmbeddings — получение векторных представлений текста
- Chroma — хранение и поиск векторных представлений документов
- Pandas — загрузка и подготовка табличных данных

## Принцип работы

1. Данные научных статей загружаются из CSV-файла.
2. Записи преобразуются в документы, с которыми работает LangChain.
3. Для документов используются векторные представления и коллекция Chroma.
4. По запросу пользователя выполняется поиск релевантной информации.
5. Найденные материалы передаются языковой модели GigaChat в качестве контекста для ответа.

Схема RAG-пайплайна:

```text
CSV с данными статей
        ↓
Подготовка документов
        ↓
Эмбеддинги и Chroma
        ↓
Поиск по запросу пользователя
        ↓
Контекст + GigaChat
        ↓
Ответ
```

## Запуск

Для работы необходим Python и доступ к GigaChat API.

```bash
git clone https://github.com/Lisa15080/prompt-engineering_rag_lab.git
cd prompt-engineering_rag_lab
python -m venv .venv
source .venv/bin/activate
```

На Windows активация окружения:

```powershell
.venv\Scripts\activate
```

Установить используемые библиотеки (версии необходимо согласовать с кодом проекта):

```bash
pip install pandas langchain langchain-community langchain-core langchain-chroma chromadb langchain-gigachat
```

Перед запуском необходимо:

- настроить доступ к GigaChat API и хранить учётные данные в переменных окружения, а не в исходном коде;
- указать путь к исходному CSV-файлу;
- подготовить или подключить коллекцию Chroma, которую использует программа.

Основной файл проекта:

```bash
python main.py
```

> В текущем виде проект может требовать локального CSV-файла и заранее созданной базы Chroma. Поэтому запуск в чистом окружении без подготовки данных не гарантируется.
